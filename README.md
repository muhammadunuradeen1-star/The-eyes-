# The Eyes — Field Agent Prototype V1

A Codex-ready specification repository for the Field Agent portion of The Eyes election monitoring and reporting platform.

## Scope

V1 covers:
- Polling Unit Agent dashboard and reporting workflows
- Ward Collation Agent dashboard
- Polling-unit upload review
- Ward-level collation submission workflows
- User profiles
- Evidence-upload prototypes
- E-Form prototype framework
- Simulated votes/status data

## Important

This is a prototype. Election data, uploads, timestamps, votes, and statuses are simulated. No live electoral data source is connected.

## Documentation

- `AGENTS.md` — persistent Codex project instructions
- `docs/product-specification.md` — product requirements
- `docs/user-flows.md` — approved workflows
- `docs/data-model.md` — proposed prototype entities
- `docs/design-system.md` — UI/UX direction
