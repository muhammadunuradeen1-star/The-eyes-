# The Eyes — Design System V1

## Design objective

Create a modern, cutting-edge interface appropriate for a serious election monitoring and reporting platform.

## Visual direction

- Deep navy/midnight foundation
- Blue/cyan interaction accents
- Green success states
- Amber warning states
- Red critical states
- Slate neutral surfaces
- Strong contrast
- Minimal decorative noise

## UI principles

1. Mobile-first
2. Touch-friendly controls
3. Clear hierarchy
4. One primary action per screen where practical
5. Persistent role/context visibility
6. Clear status labels
7. Fast navigation
8. Accessible focus states
9. Responsive tables
10. Explicit prototype/simulated-data labeling

## Core components

- App shell
- Top navigation
- Role navigation
- Dashboard cards
- Action cards
- Breadcrumbs
- Status badges
- Evidence upload component
- E-Form component
- Submission table
- Submission detail drawer/page
- Confirmation dialog
- Toast
- Empty state
- Error state
- Loading state

## Responsive behavior

Desktop:
- Persistent sidebar
- Dense operational dashboard
- Tables where appropriate

Mobile:
- Bottom/compact navigation or collapsible navigation
- Large touch targets
- Card-based submission rows
- Full-width forms
- Avoid clipped tables

## Accessibility

- Semantic controls
- Keyboard navigation
- Visible focus
- Adequate contrast
- Labels for inputs
- Screen-reader-friendly status updates
