# V1 Acceptance Criteria

## Polling Unit Agent

- [ ] Dashboard exposes Upload, User Profile and Log Out.
- [ ] Upload opens all four election choices.
- [ ] Presidential Election opens Successful Election, Over Voting and Violence.
- [ ] Successful Election exposes EC8A, E-Form, Video and Duplicate Copy.
- [ ] Over Voting exposes EC8A, E-Form, Video and Duplicate Copy.
- [ ] Violence exposes EC40G, E-Form, Video and Duplicate Copy.

## Ward Collation Agent

- [ ] Dashboard exposes User Profile, View Upload, Upload and Votes.
- [ ] View Upload exposes all four election categories.
- [ ] Polling-unit submission viewer exposes the required evidence/time/status fields.
- [ ] Senate view supports Senatorial Zone.
- [ ] House of Representatives view supports Constituency.
- [ ] Upload exposes the four collation categories.
- [ ] Collation status exposes Successful Ward Collation, Over Voting, Violence and Expose.
- [ ] Successful Ward Collation exposes EC8A, E-Form, Duplicate Copy and Video.
- [ ] Over Voting exposes EC8A, E-Form, Duplicate Copy and Video.
- [ ] Violence exposes EC40G, E-Form, Video and Duplicate Copy.
- [ ] Expose exposes Original Copy and Altered/Fake Copy.

## General

- [ ] Prototype data is clearly simulated.
- [ ] Navigation works on desktop and mobile.
- [ ] Core workflows have automated tests.
- [ ] No live election feed is connected.
- [ ] No missing electoral form fields are invented.
